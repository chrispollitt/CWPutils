Finding memory bugs
  Cygwin's g++ has no ASan/UBSan runtime and there is no valgrind.  Build a
  copy on Linux with CXXFLAGS="-g -O1 -fsanitize=address,undefined" and
  LDXXFLAGS="-fsanitize=address,undefined" (edit config.mk), then `make test`.

Testing against different kernels
  t/fakekernel.pl MODE SCRIPT [ARGS] execs a script's interpreter the way a
  linux (one arg), naive (split on whitespace) or perfect (shell-like split)
  kernel would.  Build env2 with the matching KERNEL_SPLIT and call it through
  the shim to test a flavour you do not have.  configure honours
  KERNEL_SHIM=linux|naive|perfect, and test_configure.sh (run by `make test`)
  uses that to check what configure picks for each flavour and that env2 works
  with it.  It works in a scratch copy because configure runs `make clean`.

Comparing the splitters with Perl's shellwords()
  t/splitcheck.cc runs env2's splitter on lines from stdin; t/splitcompare.pl
  generates every string up to a given length over a small alphabet (a b space
  tab, single quote, double quote, backslash) and reports where env2 and
  Text::ParseWords::shellwords() disagree.  `make splitcheck` builds the harness.
    perl t/splitcompare.pl ./splitcheck S 6         # shellwords port: must be 0 differences
                                                    #   (run by make test, at length 5)
    perl t/splitcompare.pl ./splitcheck sp 6        # the original splitter (flags: s p x c)
    SPLITCMP_WS=1 perl t/splitcompare.pl ./splitcheck S 5   # CR, FF, VT as whitespace
  The original splitter's differences are listed in the man page (QUOTING AND ESCAPES, BUGS).
